Developer Integration

Complete guide for integrating official Sri Lanka election symbols into your web applications. Supports React/Next.js tree-shaking, Vue 3, vanilla TypeScript/ESM, and on-demand CDN loading.

1. Package Installation

Install the official icon suite via npm, pnpm, yarn, or bun, or load icons on-demand via CDN.

Terminal 
# npm
npm install @numberslk/icons

# pnpm
pnpm add @numberslk/icons

# yarn & bun
yarn add @numberslk/icons
bun add @numberslk/icons

2. React & Next.js

Tree-shakable components with TypeScript definitions, forwardRef, and Tailwind CSS support.

React / JSX 
import { ElephantIcon, CompassIcon } from '@numberslk/icons/election-symbols';
// Or root import: import { ElephantIcon } from '@numberslk/icons';

export function ElectionHeader() {
  return (
    <div className="flex gap-4 items-center">
      <ElephantIcon size={32} color="#dc2638" />
      <CompassIcon size={32} className="text-slate-800 dark:text-slate-100" />
    </div>
  );
}

3. Vanilla JS & TypeScript

Zero-dependency helper functions or direct SVG string imports for any web application.

JavaScript 
import { getSymbolSvg, searchSymbols } from '@numberslk/icons/election-symbols';

// Search by political party acronym or name
const matches = searchSymbols('NPP');

// Render 512px SVG string
const svg = getSymbolSvg('compass', { size: 48, color: '#dc2638' });
document.getElementById('iconStage').innerHTML = svg;

4. Election Context Syntax & Web Components

Access symbols dynamically by election year, election type, district, and party or candidate group (e.g. Compass via <lk-election-symbols-2025-pres-national-NPP>).

HTML / Web Component 
<!-- 1. Web Component (Direct Custom Element) -->
<lk-election-symbols-2025-pres-national-NPP size="48"></lk-election-symbols-2025-pres-national-NPP>
<lk-election-symbols-2024-pres-national-SJB size="48"></lk-election-symbols-2024-pres-national-SJB>

<!-- 2. Generic Web Component -->
<lk-election-symbol name="2025-pres-national-NPP" size="48"></lk-election-symbol>

<!-- 3. JavaScript / TypeScript Resolver -->
<script type="module">
  import { resolveElectionSymbol, getSymbolSvg } from '@numberslk/icons/election-symbols';
  const compass = resolveElectionSymbol('<lk-election-symbols-2025-pres-national-NPP>');
  console.log(compass.name); // Compass
</script>
